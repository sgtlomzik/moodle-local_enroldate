# Enrolment with date selection

Moodle local plugin `local_enroldate`.

Lets enrolment be created with an explicit start date chosen by the operator, and keeps grade visibility consistent with that date.

## Requirements

- Moodle with version number `2020110900` or later.

## Installation

Copy the plugin folder to `local/enroldate` in your Moodle root, then visit
**Site administration → Notifications** to complete the database upgrade.

```
<moodle>/local/enroldate
```

## Version

Release `1.2.1`. See `version.php` for the exact version number.
